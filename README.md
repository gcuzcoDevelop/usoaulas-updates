# usoaulas-updates

Canal de actualizaciones del agente "Registro de uso de aula"
(piloto de monitoreo de pantallas interactivas, UNACH).

- `update.json` (raíz): manifiesto de la última versión. URL estable que
  configuran las pantallas en Config -> Actualizacion.
- Releases: un `usoaulas-<version>.apk` firmado por version.

El codigo fuente del piloto no se publica aqui.
